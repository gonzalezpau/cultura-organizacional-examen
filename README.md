# Cultura organizacional — Guía interactiva

Guía de estudio en español para preparar un examen sobre los cuatro tipos de cultura organizacional:

- **Orientada al poder:** autoridad, jerarquía y control.
- **Orientada a las normas:** procedimientos, reglas y estabilidad.
- **Orientada a resultados:** objetivos medibles, eficiencia y productividad.
- **Orientada a las personas:** bienestar, motivación y desarrollo.

## Contenido

- Resumen visual de los cuatro tipos.
- Definiciones, pistas, ventajas, riesgos y ejemplos.
- Método para resolver casos prácticos.
- Casos desplegables de la vida real.
- Tarjetas de memoria interactivas.
- Práctica autocorregible y simulacro de 10 preguntas.
- Lista de repaso e impresión/guardado a PDF.

## Uso local

Abre `index.html` en cualquier navegador moderno. No requiere instalación ni dependencias externas.

## Publicación con GitHub Pages

En **Settings → Pages**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/(root)`, y pulsa **Save**. Al publicarse, el sitio estará en:

https://gonzalezpau.github.io/cultura-organizacional-examen/
